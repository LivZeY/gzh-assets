# gzh-assets

WeChat article image host. Images are referenced via jsDelivr:/n/n    https://cdn.jsdelivr.net/gh/LivZeY/gzh-assets@main/<file>

Filenames carry a content hash (date-<md5-6>-name.ext) so a changed image
always gets a new URL and CDN caches never serve stale content.
Uploaded by the `gzh-editor` skill (`scripts/host_images.py`).
